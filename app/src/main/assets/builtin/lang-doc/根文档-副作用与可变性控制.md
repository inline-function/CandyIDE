# 变量

> 可变变量除了自反外，不承认它与其他表达式的相等命题

变量默认是不可变的，除非注解`@mut`。

如果你真的想让可变变量配合上下文系统，我们建议直接写一个新的不可变变量赋值它，或者用`let`函数。下面也是一样的道理，证明不可变的最好办法，就是让编译器看见你亲自把可变性割掉。

## 函数

> 不纯函数的调用是不纯表达式，不承认不纯表达式的相等命题，包括自反

函数在没有标注`@impure`的时候，默认就是纯函数。

纯函数有它的自然命题`pure<f>`，若不纯函数证明该命题，则认为是纯函数。

纯函数必须做到如下三个要求：

+ 体内不能有不纯的表达式

+ 不能修改外部捕获的可变变量

+ 必须证明自己停机

标注时，解除上述限制。

关于递归对的停机证明有两：

其一是证明每次递归的时候，递归的函数参数是原先的子结构，并且在递归到空结构时停止。

其二是证明每次递归的时候，递归的函数参数向着某个数值靠拢，并且在递归到那个数值的时候停止。

函数的参数类型可变时，函数必须标注`@impure`。

# 可变结构体

> 不承认可变结构体与其他表达式的相等命题

为结构体标注@mut，表示允许结构体声明可变属性。

结构体的属性可以注解`@mut`，此时结构体的属性可变。

```
@mut
struct T(@mut n : Nat)
```

修改结构体的可变属性，需要变量对的结构体类型可变，在结构体类型前面加上`@mut`表示变量的结构体可变。

```
var a : @mut T = T(0)
var b : T = T(0)
a.n = 1 //正常
//b.n = 1 编译不通过
```

# 可变类型

> 不承认可变类型与其他表达式的相等命题

为类型类注解`@mut` ，表示允许类型类声明可变函数。

类型类的函数可以注解`@mut`，即可变函数，这表示这个函数只能在类型可变的时候调用，可变函数可以修改实现时结构体的可变属性。

类型可以注解`@mut`，这表示类型是**可变类型**

```
@mut
class T {
    @mut
    fun add(n : Nat)
}
```

# 可变拷贝

> 对函数深拷贝时，深拷贝函数闭包捕获的变量

可变类型与不可变类型之间的类型转换是隐式的，并且会触发深拷贝。

可变类型转可变类型也会发生深拷贝。

```
var a : @mut T = T(0)
var b : T = a
a.n = 1
print(b.n) //此时仍然是0
```

```
var a : T = T(0)
var b : @mut T = a
b.n = 1
print(a.n) //此时仍然是0
```

```
var a : @mut T = T(0)
var b : @mut T = a
b.n = 1
print(a.n) //此时仍然是0
```

对于可变类型变量，如果明确想分享同一个对象，需要为变量标注`@ref`。

可变引用传给不可变引用，修改可变引用的结构体，不可变引用会观察到结构体变化，只是不可变引用没有对结构体的修改权而已，并且引用是别名语义。

```
@ref var a : @mut T = T(0)
@ref var b : @mut T = a
b.n = 1
print(a.n) //此时是1
```

```
@ref var a : @mut T = T(0)
@ref var b : T = a
a.n = 1
print(b.n) //此时是1
```

当引用变量和非引用变量互传时，会触发深拷贝。

```
@ref var a : @mut T = T(0)
var b : @mut T = a
a.n = 1
print(b.n) //此时是0
```

```
var a : @mut T = T(0)
@ref var b : @mut T = a
a.n = 1
print(b.n) //此时是0
```
