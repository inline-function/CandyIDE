# 模式匹配

## 表达式分支

表达式分支用于判断模式匹配的判断主体是不是相等于分支的表达式。

```
when(1){
    1 =>
    2 =>
    3 =>
    else =>
}
```

表达式分支的分支命题是判断主体与分支的表达式的相等命题（比方说这里第一个分支的分支命题是`1 = 1`）

## 类型分支

类型分支用于判断模式匹配的判断主体是不是某个类型。

```
when(1) {
    is Nat =>
    is Int =>
    is Rat =>
    else =>
}
```

类型分支的分支命题是判断主体与分支的类型的为命题（比方说这里第一个分支的分支命题是`1 : Nat`）

## 守卫

在分支中可以加入if子句附加逻辑判断。

```
when(n) {
    is Nat if n > 10 =>
    is Nat =>
    else =>
}
```

第一个分支的分支命题是`n : Nat`和`n > 10`的合取。

## 顺序与穷尽性

模式匹配是顺序的，因此后面的分支有前面的分支的命题的否定。

如果可以证明模式匹配所有分支的析取命题，那么认为模式匹配是穷尽的，返回类型为所有分支的联合类型；如果没有证明，则认为模式匹配没有穷尽，此时固定返回Null。

## 解构

解构在变量，函数参数中都能看到，这里主要讲解模式匹配中的。

模式匹配的is判断枚举或者结构体的时候可以对它解构。

```
when(o) {
    is Optional::Some(o) => 
    is Optional::None =>
}
```

这里对Some解构；还可以对结构体解构：

```
struct T(a : Nat,b : Nat)
when(o) {
    is T(a,b) =>
    else =>
}
```

## 模板模式匹配

在判断框内的`_`会被替换为分支主体。

```
when(n in _) {
    0 ..10 => print(1)
    11..20 => print(2)
    21..30 => print(3)
}
```

等同于

```
when {
    n in (0 ..10) => print(1)
    n in (11..20) => print(2)
    n in (21..30) => print(3)
}
```
