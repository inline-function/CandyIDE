## 调用法

### 中缀调用法

对于双参函数，或是有单参的类型类函数，可以使用中缀调用法。

```
1 + 2 //等于1.+(2)
```

### 扩展调用法

任意有参函数的首参可以移动到它的接收者位置，解析时如果与类型类冲突，优先类型类。

```
o.f(1,2,3) //等于f(o,1,2,3)
```

### 尾随调用法

如果函数的尾参是函数类型，则匿名函数可以写出函数外。

```
list.map { e => e + 1 } //等于list.map({ e => e + 1 })
```

### 指名调用法

只支持用fun声明的函数，使用指名调用来按名字传入参数。

```
o.f(b = 1,a = 2) //f(a,b)则等于o.f(2,1)
```

## 默认单参

匿名函数只有一个参数的时候，可以省略，用`_`表示。

```
var lambda : (Nat)=>Nat = { _ + 1 }
```

## 模板模式匹配

在模式匹配的判断主体中的`_`会被替换为分支内容。

```
when(n in _) {
    0 ..10 => print(1)
    11..20 => print(2)
    21..30 => print(3)
}
```

也就是

```
when {
    n in (0 ..10) => print(1)
    n in (11..20) => print(2)
    n in (21..30) => print(3)
}
```

## if-is解构

类似于rust的if-let，在类型判断中对对象进行解构。

```
if(str is Some(str))
    print(str)
else
    print("null")
```
