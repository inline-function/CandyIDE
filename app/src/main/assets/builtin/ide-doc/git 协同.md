# git 协同

CandyIDE 的 git 能力由协同应用提供：

- **Shizuku**：让命令直接在本机执行（终端页里可用）
- **Termux**：提供 git 二进制与包管理器（pkg）

两个都装上体验最完整。首次使用时如果检测到缺协同应用，IDE 会弹对话框给出下载链接，
安装后回到 IDE 自动刷新状态（✓/✗ 实时变化），两个都装上对话框自动关闭。

## git 初始化

装好 Termux 后，IDE 会询问是否初始化 git（执行 `pkg install git`）。
稍后再装也可以：设置 → git 协同 → 安装 git。

- 没装 Termux：先提示装 Termux（附下载链接），装好回来自动继续
- 已装 Termux：直接问是否安装 git
- 已装 git：再点提示“您已安装git”

创建工程时会自动初始化 git 仓库（若协同应用就绪）。

## git 页面（编辑页长按第 4 按钮）

- **推送 (Commit)**
  - 短按：保存到本地，弹对话框填存档名（默认“第 n 次推送”）
  - 长按：保存并推送到云端（push）
- **丢弃 (Discard)**
  - 短按：丢弃所有未提交的修改，还原到最近的保存
  - 长按：按提交时间选择版本回退（Reset）

每次进入工程（开启“自动同步云端”时）或使用 git 功能前，IDE 会检测云端是否有更新，
有更新提示拉取；如果拉取发生冲突，会弹对话框选择解决方式（保留本地 / 用云端覆盖）。

## IDE 设置 → git 协同

- **个人信息**：用户名 / 邮箱 / 远程仓库地址（https 或 ssh）
- **修改文件自动提交**：保存、删除、新建文件时自动提交，提交名形如“修改 hello.subl 文件”“删除 src 目录”
- **自动同步云端**：进入工程自动拉取；开启自动提交时一并推送（手动推送不受影响）

## 工作区真实路径

工程目录在系统里的真实路径可以在 `project_info` / `workspace_info` 工具里看到，
终端里跑 git 等命令时用它作为工作目录。
