# 开始使用

CandyIDE 是移动端的 Sublimation 语言集成开发环境。

## 创建工程

1. 主页点右下角加号
2. 输入工程名称
3. 选择工程类型：
   - JS工程：将Subl编译为JS代码，可打包为控制台APK
   - 脚本工程：Subl 顶层语句直接解释执行
   - 安卓工程：编译后注进模板 APK 安装
   - MD工程：把工程里的 .md 打包成只读文档 APK

创建工程时会自动初始化 git 仓库（Termux 就绪时）。

## 文件树

编辑页左上角菜单打开文件树。长按目录/文件弹操作菜单：创建子文件、重命名、复制、剪切、删除、压缩为 zip、复制路径。

多选模式：点右上角多选按钮，可批量删除/复制/剪切/压缩。
