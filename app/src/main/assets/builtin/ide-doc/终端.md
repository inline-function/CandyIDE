# 终端

- 主页右上角「终端」按钮进入终端页（仿终端界面）
- 命令通道：Shizuku 优先（以 shell 身份执行）；git 等命令自动走 Termux RUN_COMMAND
- 支持 `cd`/`pwd` 等内置命令与外部命令，提示符显示当前目录

## Termux 授权

Termux 默认不允许其它应用执行命令。进终端页时如果 Termux 已装但未授权，
会弹「需要开启 Termux 外部调用」：点「去开启」会自动复制命令并跳转 Termux，
粘贴执行一次（系统询问存储权限时同意），之后再回车一次即可。

也可以在 设置 → Shizuku 权限 → Termux 授权 里主动请求 RUN_COMMAND 权限。
