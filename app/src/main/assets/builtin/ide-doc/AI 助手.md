# AI 助手

悬浮球（设置里开关）或更多菜单进 AI 助手页。

- 往期对话：保存与恢复历史会话
- 工作区与权限：查看 agent 的工具与权限状态
- 输入框左侧锁图标：切换访问权（只读 / 当前工程 / 当前 IDE 目录 / 完全访问）
- 输入框上方 token 条：显示本次对话剩余可用量
- 回复中出现【选项：A|B|C】会渲染成选项按钮

助手旁的状态：思考中 / 阅读中（读文件）/ 编辑中（写文件）/ 操作中（跑命令）。随时可停止。

shell 工具（run_shell）里普通命令经 Shizuku 执行；git 相关命令会自动改走 Termux 通道
（Shizuku 的 shell 环境里没有 git）。
