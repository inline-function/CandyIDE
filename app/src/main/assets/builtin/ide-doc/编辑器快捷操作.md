# 编辑器快捷操作

## 长按

长按词/函数名弹出快捷操作：

- 指名调用：给函数调用补上形参名（如 `print(value = 1)`）
- 转到定义
- 重命名

## 双击

双击词弹出文本操作菜单：全选/复制/剪切/粘贴。

## 顶栏按钮

从左到右：文件树、保存（长按保存全部工程文件）、撤销（长按出拖动条）、运行（长按打包 APK）、输出/日志/诊断（长按打开 git 面板）、其他操作（长按工程设置）。

## git 面板（右侧抽屉）

长按「输出/日志/诊断」按钮从右侧滑出 git 面板：

- 远程仓库地址：每个工程独立保存
- 推送（短按本地提交 / 长按推送云端）
- 丢弃（短按还原未提交修改 / 长按版本回退）

## 补全条目长按

补全弹窗里长按条目：函数名插入指名调用骨架，关键词插入完整语句骨架。
